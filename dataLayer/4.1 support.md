## 1. События

Кнопка «В поддержку» в визитке открывает чат на сайте.

Передавайте события по [Общим правилам dataLayer](1.%20dataLayer.md).

| Событие | Когда отправлять |
| --- | --- |
| `support_chat_triggered` | При принятии команды открыть чат из визитки |
| `support_chat_started` | После подтверждения, что чат открыт и готов принять сообщение |

## 2. Порядок отправки

1. Перед вызовом открытия создайте попытку: `attempt_id = newId()`, `object_version` из конфигурации. Отправьте `support_chat_triggered` с `event_sequence = 1`.
2. При подтверждении готовности отправьте `support_chat_started` с тем же `attempt_id`, сохранённой `object_version` и `event_sequence = 2`.
3. На время открытия и работы чата сохраняйте одну попытку. Каждое событие отправляйте один раз на попытку; callback готовности, закрытия и ошибки обрабатывайте только для действующего запуска.
4. Завершайте локальную попытку по подтверждённому закрытию чата или ошибке открытия. При следующей принятой команде создавайте новую попытку с новым `attempt_id` и номером `1`.
5. Между перезагрузками сохраняйте и восстанавливайте `attempt_id`, `object_version`, счётчик, состояние запуска и признаки отправленных событий.
6. Для каждого факта создавайте `event_id = newId()` и фиксируйте `occurred_at = new Date().toISOString()`. При повторной доставке сохраняйте исходное сообщение.
7. Получайте `schema_version` из сборки для пары «`event` + `object_version`».

## 3. Примеры сообщений

Используйте состав сообщений из примеров; UUID, время и версии приведены для иллюстрации.

Принята команда открыть чат:

```js
window.dataLayer.push({ payload: null });

window.dataLayer.push({
  event: 'support_chat_triggered',
  event_id: 'c4eb8d71-2fa6-4e90-9b35-7d0612c8fa43',
  occurred_at: '2026-09-09T16:23:53.120Z',
  schema_version: '1:1',
  source: 'web',
  object_class: 'process',
  object_type: 'flow',
  object_name: 'support_chat',
  object_version: 1,
  payload: {
    attempt_id: 'f2a67419-8bd3-4ce0-a175-6d092eb834fc',
    event_sequence: 1,
    trigger_type: 'user_action',
    trigger_source: 'support_card'
  }
});
```

Чат этого же запуска открыт и готов принять сообщение:

```js
window.dataLayer.push({ payload: null });

window.dataLayer.push({
  event: 'support_chat_started',
  event_id: 'ab6310d2-e9f4-47a8-b650-3c71d29e084f',
  occurred_at: '2026-09-09T16:23:53.840Z',
  schema_version: '1:1',
  source: 'web',
  object_class: 'process',
  object_type: 'flow',
  object_name: 'support_chat',
  object_version: 1,
  payload: {
    attempt_id: 'f2a67419-8bd3-4ce0-a175-6d092eb834fc',
    event_sequence: 2
  }
});
```
