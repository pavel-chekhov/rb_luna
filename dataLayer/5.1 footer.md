## 1. События

Футер — подвал сайта, общий для всех страниц. Передавайте события по [Общим правилам dataLayer](1.%20dataLayer.md).

| Событие | `object_type` | Когда отправлять |
| --- | --- | --- |
| `contact_link_activated` | `contact_link` | При активации Telegram или email пользователем |
| `menu_item_activated` | `menu_item` | При активации пункта колонки «Категории» пользователем |

## 2. Элементы

| Элемент интерфейса | `object_name` | Полный `payload` |
| --- | --- | --- |
| Telegram | `telegram` | `{"container_type": "footer_brand"}` |
| Почта поддержки | `support_email` | `{"container_type": "footer_column", "container_name": "contacts", "element_position": 1}` |
| Коммерческая почта | `commercial_email` | `{"container_type": "footer_column", "container_name": "contacts", "element_position": 2}` |
| «Игры» в колонке «Категории» | `home` | `{"container_type": "footer_column", "container_name": "categories", "element_position": 1}` |
| «Турниры» в колонке «Категории» | `tournaments` | `{"container_type": "footer_column", "container_name": "categories", "element_position": 2}` |
| «Бонусы» в колонке «Категории» | `bonuses` | `{"container_type": "footer_column", "container_name": "categories", "element_position": 3}` |

## 3. Порядок отправки

1. Отправляйте событие в обработчике пользовательской активации.
2. Каждую повторную активацию учитывайте новым событием.
3. Для каждого факта создавайте `event_id = newId()` и фиксируйте `occurred_at = new Date().toISOString()`.
4. При повторной доставке сохраняйте исходное сообщение.
5. Берите имена и состав свойств из [раздела 2](#2-элементы). Определяйте `element_position` по текущему порядку в колонке сверху вниз, начиная с `1`; в таблице указан текущий порядок элементов.
6. Получайте `object_version` из конфигурации, `schema_version` — из сборки для пары «`event` + `object_version`».
7. Перед каждым событием выполняйте `window.dataLayer.push({ payload: null })`.

## 4. Примеры сообщений

Используйте состав сообщений из примеров; UUID, время и версии приведены для иллюстрации.

Активирована кнопка Telegram:

```js
window.dataLayer.push({ payload: null });

window.dataLayer.push({
  event: 'contact_link_activated',
  event_id: '3a8d5e17-c2b4-4d69-8f01-5b7e9c2d4a86',
  occurred_at: '2026-09-10T09:41:05.284Z',
  schema_version: '1:1',
  source: 'web',
  object_class: 'ui_element',
  object_type: 'contact_link',
  object_name: 'telegram',
  object_version: 1,
  payload: {
    container_type: 'footer_brand'
  }
});
```

Активирована почта поддержки — первая в колонке `contacts`:

```js
window.dataLayer.push({ payload: null });
```
