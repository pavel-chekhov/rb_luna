## 1. События

Welcome Pack — промо-баннер и бар быстрых переходов над каталогом игр на главной странице. Передавайте события по [Общим правилам dataLayer](1.%20dataLayer.md).

| Событие | `object_type` | Когда отправлять |
| --- | --- | --- |
| `banner_activated` | `banner` | При активации промо-баннера пользователем |
| `button_activated` | `button` | При активации кнопки бара пользователем |

## 2. Элементы

| Элемент интерфейса | `object_name` | Полный `payload` |
| --- | --- | --- |
| Промо-баннер | `welcome_pack` | `{"container_type": "promo_header"}` |
| Бонусы | `bonuses` | `{"container_type": "shortcut_bar", "element_position": 1}` |
| Ежедневные турниры | `daily_tournaments` | `{"container_type": "shortcut_bar", "element_position": 2}` |
| Колесо фортуны | `fortune_wheel` | `{"container_type": "shortcut_bar", "element_position": 3}` |
| Скачать приложение | `mobile_app` | `{"container_type": "shortcut_bar", "element_position": 4}` |
| Программа лояльности | `loyalty_program` | `{"container_type": "shortcut_bar", "element_position": 5}` |
| Бонус в день рождения | `birthday_bonus` | `{"container_type": "shortcut_bar", "element_position": 6}` |

## 3. Порядок отправки

1. Отправляйте событие в обработчике пользовательской активации. Каждую повторную активацию учитывайте новым событием.
2. Для каждого факта создавайте `event_id = newId()` и фиксируйте `occurred_at = new Date().toISOString()`. При повторной доставке сохраняйте исходное сообщение.
3. Берите имена и состав свойств из [раздела 2](#2-элементы). Определяйте `element_position` по текущему порядку кнопок в баре, начиная с `1`; в таблице указан текущий порядок.
4. Получайте `object_version` из конфигурации, `schema_version` — из сборки для пары «`event` + `object_version`».
5. Перед каждым событием выполняйте `window.dataLayer.push({ payload: null })`.

## 4. Примеры сообщений

Используйте состав сообщений из примеров; UUID, время и версии приведены для иллюстрации.

Активирован промо-баннер:

```js
window.dataLayer.push({ payload: null });

window.dataLayer.push({
  event: 'banner_activated',
  event_id: 'f2c81a37-6b04-4e59-9d72-3a5e8c1f0b64',
  occurred_at: '2026-09-07T10:13:41.208Z',
  schema_version: '1:1',
  source: 'web',
  object_class: 'ui_element',
  object_type: 'banner',
  object_name: 'welcome_pack',
  object_version: 1,
  payload: {
    container_type: 'promo_header'
  }
});
```

Активирована кнопка `Колесо фортуны` — третья в баре:

```js
window.dataLayer.push({ payload: null });

window.dataLayer.push({
  event: 'button_activated',
  event_id: '5d93e07b-1a26-4c8f-b350-9e2f7d4a6c18',
  occurred_at: '2026-09-07T10:13:52.774Z',
  schema_version: '1:1',
  source: 'web',
  object_class: 'ui_element',
  object_type: 'button',
  object_name: 'fortune_wheel',
  object_version: 1,
  payload: {
    container_type: 'shortcut_bar',
    element_position: 3
  }
});
```
